# Pku-Course-Helper
这个项目起源于2025春季的程序设计与实践课程的qt大作业，我们开发一个根据课程各项得分和用户的标签及希望进行课程推荐的软件——pku course helper。它将帮助P大的学生光速查找到适合自己的课程并提供课程简介的链接，方便了解更多详细信息，它的效率会比选课网逐个查询高出很多，同时它将具有随机推荐的功能，可以帮助我们探索P大的各类或热门或冷门的课程——你大可以不断进行随机推荐知道一个课的名字吸引住你的注意力。
然而本项目几乎全由一个人完成，仅有另一位同学参与了数据处理，不过这位同学因某些原因休学，数据中评分相关分数原计划从非官方课程评测网站爬取，现今却改为了随即数据。（25.5.31.02.46）
